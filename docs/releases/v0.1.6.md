## Summary

`parakeet-cli` v0.1.6 introduces a session-aware daemon protocol, bounded audio segmentation, and explicit reporting of capture and recognition failures. It is the engine used by Superkeet v1.6.0.

## What's Changed

- added `parakeet protocol-version` and protocol-1 UTF-8 NDJSON daemon events
- added client session identifiers and definite completion events for successful, partial, empty, and failed sessions
- preserved embedded newlines in transcript messages through JSON string escaping
- moved microphone collection onto an independent thread, with overflow accounting and stop-time draining of queued audio and the resampler tail
- replaced the daemon's sliding utterance buffer with bounded segments and overlapping recognition context
- added `transcribe --session --format json` to replay WAV recordings through the session segmentation and recognition path
- surfaced decoder iteration-limit failures instead of returning an incomplete segment as successful
- separated daemon control, protocol framing, collection, runtime files, and inference delivery; consolidated checksum and mono-conversion helpers
- removed obsolete daemon code and explanatory source comments while preserving CLI help through explicit metadata

## Integration Migration

**Daemon stdout now contains JSON events rather than plain transcript lines.** Read the `text` field of the `complete` event and inspect its `status`, `failed_segments`, and `dropped_samples` fields. A stop acknowledgement means processing is pending; wait for completion before starting another session.

```json
{"command":"start","session_id":"unique-client-session"}
{"command":"stop","session_id":"unique-client-session"}
```

Bare socket commands, toggle/stop signals, clipboard output, and socket capture remain available. Ordinary file transcription and `listen` retain their existing interfaces. See [daemon protocol 1](https://github.com/lucataco/parakeet-cli/blob/v0.1.6/docs/session-protocol.md) for the wire contract and examples.

## Validation and Known Limitations

- 47 Rust tests pass, including protocol framing, completion status, sample conservation, stop draining, and queue-overflow cases
- formatting, all-target Clippy, release build, and compilation of all seven benchmark targets pass
- the Superkeet real-daemon protocol smoke test passes
- the eight-case synthetic-audio suite passes four strict word/count scenarios; auth/off substitutions, correction-marker recognition, repeated answers, and long-session word/count errors remain documented failures
- zero reported queue drops does not guarantee word-perfect recognition; human complaint recordings were unavailable

## Build from Source

```bash
git clone --branch v0.1.6 https://github.com/lucataco/parakeet-cli.git
cd parakeet-cli
cargo build --release --locked --bin parakeet
```

macOS on Apple Silicon remains the supported target. Downloads default to the INT8 Parakeet TDT 0.6B v3 model; FP16 remains available with `download --fp16`.
