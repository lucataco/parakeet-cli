## Summary

`parakeet-cli` v0.1.4 is a patch release focused on transcription correctness, daemon reliability, and cleaner command output for integrations like Superkeet.

## What's Changed

- kept verbose diagnostics on stderr so `transcribe --format json --verbose` still emits valid JSON on stdout
- fixed model variant selection so an INT8 download is honored even when FP16 files also exist
- ignored incomplete higher-priority model variants instead of failing when a complete lower-priority variant is available
- fixed TDT decoder handling for non-blank zero-duration tokens
- aligned mel spectrogram framing with centered STFT padding
- added support for more microphone sample formats
- fixed daemon capture races and stop/cancel edge cases
- validated VAD thresholds and rounded VAD silence windows up instead of down

## Install / Upgrade

```bash
brew update
brew upgrade lucataco/tap/parakeet-cli
```

## Notes

- macOS on Apple Silicon remains the supported target
- `parakeet download` defaults to the smaller INT8 Parakeet TDT 0.6B v3 model
- use `parakeet download --fp16` for the larger FP16 weights
