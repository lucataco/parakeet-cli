## Summary

`parakeet-cli` v0.1.5 adds machine-readable download progress so host applications (like Superkeet) can drive a native, first-run model-download experience instead of parsing human progress bars.

## What's Changed

- added `parakeet download --progress json`, which emits newline-delimited JSON events (`start`, `fileStart`, `fileProgress`, `fileComplete`, `complete`, `error`) on stdout
- kept the default `--progress auto` behavior (human-readable progress bars on stderr) unchanged for interactive use
- throttled JSON progress events to avoid flooding consumers, and flushed each event on its trailing newline for timely updates

## Install / Upgrade

```bash
brew update
brew upgrade lucataco/tap/parakeet-cli
```

Or build from source:

```bash
git clone https://github.com/lucataco/parakeet-cli.git
cd parakeet-cli
cargo build --release --bin parakeet
```

## Quick Start

```bash
parakeet download
parakeet devices
parakeet listen
```

For integrations, stream machine-readable progress:

```bash
parakeet download --progress json
```

## Notes

- macOS on Apple Silicon remains the supported target
- `parakeet download` defaults to the smaller INT8 Parakeet TDT 0.6B v3 model
- use `parakeet download --fp16` for the larger FP16 weights
